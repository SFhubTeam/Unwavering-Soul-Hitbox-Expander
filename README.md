# 💀 SFhub // UNWAVERING SOUL HITBOX HUB [KEYLESS]

Welcome to the official repository of **SFhub** for Roblox **Unwavering Soul**! This is a secure, 100% working raw Lua script base with an integrated minimalist custom GUI. No external internet loaders required, completely safe from crashes and anti-cheat detections.

---

## ⚡ FUNCTIONS:
* **[+] Hitbox Expander** — Increase boss hitboxes to easily defeat them from any distance.
* **[-] Reduce Hitbox** — Fine-tune hitbox size via custom buttons to avoid public detection.
* **[🚷] No Collision** — Walk directly through expanded hitboxes without glitching, lagging, or rubberbanding.
* **[🛡️] Anti-Idle** — Built-in protection against the 20-minute Roblox AFK kick system.
